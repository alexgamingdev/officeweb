### How to redeem

1. Visit [officeweb.app](https://officeweb.app) (or your hosted instance).
2. Scroll to the **Promo Code** section on the homepage.
3. Enter the code **`OFFICEWEB1000`** and click **Activate**.
4. Your Pro features are now unlocked – no account needed, no expiry.

### Notes

- The code is **permanent** (no expiration date).
- The code has **unlimited uses** – every member of the community can redeem it.
- Activation is stored locally in the browser (`localStorage`). It will persist across page reloads on the same device/browser.
